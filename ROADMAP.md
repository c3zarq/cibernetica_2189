# ROADMAP
## Cyberpunk Open World RPG

Versão: 0.1

## PRINCÍPIO

Cada etapa deverá produzir uma funcionalidade executável e testável.

Não iniciar uma nova etapa enquanto a anterior não estiver validada.

---

## FASE 0 — Validação tecnológica

Objetivo: comprovar que a tecnologia escolhida funciona no hardware disponível.

Entregas:

1. Criar projeto utilizando Vite.
2. Instalar Three.js.
3. Configurar cena 3D.
4. Criar câmera.
5. Configurar iluminação.
6. Criar terreno.
7. Criar construções geométricas simples.
8. Implementar movimentação em primeira pessoa.
9. Implementar colisões básicas.
10. Adicionar iluminação neon.

Critérios de aceitação:

- O cenário é renderizado no navegador.
- O jogador consegue caminhar.
- A câmera responde ao mouse.
- O jogador não atravessa construções.
- A experiência apresenta desempenho aceitável.

Esta fase deverá ser pequena e servir como prova de conceito.

## FASE 1 — Mundo explorável

Objetivo: transformar a prova de conceito em um pequeno ambiente de jogo.

Entregas:

- Construir uma rua futurista.
- Adicionar prédios.
- Criar iluminação ambiental.
- Adicionar elementos urbanos.
- Implementar limites do cenário.
- Criar pontos de interesse.

Critério de aceitação:

O jogador consegue explorar uma pequena região urbana com liberdade.

## FASE 2 — Personagens e interação

Objetivo: introduzir vida ao ambiente.

Entregas:

- Criar NPCs.
- Implementar movimentação simples dos NPCs.
- Criar diálogos.
- Implementar sistema de interação.
- Criar estabelecimentos e pontos de interesse.

Critério de aceitação:

O jogador consegue encontrar personagens e interagir com eles.

## FASE 3 — Missões e economia

Objetivo: introduzir objetivos e progressão.

Entregas:

- Criar sistema de missões.
- Implementar objetivos.
- Criar sistema de dinheiro.
- Implementar pagamentos.
- Criar uma loja simples.
- Permitir aquisição de equipamentos.

Critério de aceitação:

O jogador consegue aceitar e concluir pelo menos uma missão e receber uma recompensa.

## FASE 4 — Combate

Objetivo: implementar conflitos e inimigos.

Entregas:

- Criar inimigo.
- Implementar saúde.
- Implementar ataques.
- Criar arma inicial.
- Implementar dano.
- Criar comportamento básico de perseguição.

Critério de aceitação:

O jogador consegue combater um inimigo e vencer ou perder o confronto.

## FASE 5 — Inventário e progressão

Objetivo: permitir evolução do personagem.

Entregas:

- Inventário.
- Equipamentos.
- Experiência.
- Níveis.
- Atributos básicos.
- Primeiros implantes cibernéticos.

Critério de aceitação:

O jogador consegue adquirir, armazenar e utilizar equipamentos.

## FASE 6 — Persistência

Objetivo: permitir continuidade da experiência.

Entregas:

- Sistema de salvamento.
- Recuperação de progresso.
- Persistência de inventário.
- Persistência de dinheiro.
- Persistência de missões.

Critério de aceitação:

O jogador consegue fechar o jogo e continuar de onde parou.

## FASE 7 — Consolidação do MVP

Objetivo: integrar os sistemas e produzir uma experiência jogável.

Entregas:

- Revisão de desempenho.
- Correção de erros.
- Revisão da interface.
- Ajustes de movimentação.
- Integração das missões.
- Revisão da ambientação.
- Testes completos.

Critério de aceitação:

Um jogador consegue iniciar, explorar, interagir, combater, realizar uma missão, adquirir equipamentos e salvar seu progresso.

---

## EVOLUÇÕES POSTERIORES

Não fazem parte do MVP:

- Construção modular de estruturas.
- Compra de propriedades.
- Veículos.
- Novos distritos.
- Facções.
- Reputação.
- Inteligência artificial avançada para NPCs.
- Perspectiva em terceira pessoa.
- Geração procedural de ambientes.
- Multiplayer.
- Servidor e banco de dados remoto.

Essas funcionalidades deverão ser avaliadas individualmente, conforme a evolução do projeto.
